A standalone application that signs in through Anugal CIAM. It runs a real OpenID Connect handshake: authorization code with PKCE, a token exchange, then signature verification of the ID token against the Anugal JWKS. It holds no client secret — there is nowhere in a browser to keep one. To exercise single sign-on, deploy it alongside another Anugal CIAM demo application (for example, Aurora Analytics) registered against the same customer: sign in to that one first, then open this page — it should complete with no second prompt, because the session lives in Anugal, not in either page.
